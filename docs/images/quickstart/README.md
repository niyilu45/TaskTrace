# QuickStart 配图与动图

这些素材用于仓库根目录的 [QuickStart.md](../../../QuickStart.md)。

- `maps/`：界面图解，简短中文说明与引线直接标注在图内；SVG 自带底图，不依赖外部图片。
- `gifs/w*.gif`：网页真实界面的分步截图合成，每组演示一个操作流程。
- `gifs/native-*.gif`：以生产程序的真实 Windows 控件生成的分步示意，并非连续录屏。原生画面均明确标注“真实控件分步示意（非录屏）”。
- `gifs/w07-team-sharing.gif`、`gifs/w08-import-shared-task.gif`：独立内存中的协作配置示意，持续显示说明横幅，没有实际设置 Windows 共享权限或执行局域网同步；不能用于证明网络授权或同步已经通过验证。
- `01-startup-flow.svg`：启动、显示与退出流程示意。

所有内容使用隔离演示数据。名称、成员、路径与链接仅作说明，不含实际个人任务、真实协作链接、凭据或运行数据。原始录制帧、临时生成工具和测试环境不随仓库提交。

更新素材时应同步检查：说明与界面一致；正文和关键按钮没有被标注遮挡；GIF 首尾停留足够阅读；所有文件可解码且指南中的相对链接有效。
